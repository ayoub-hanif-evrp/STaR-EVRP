# Phase 5 pre-execution protocol

This is an extension of an already-open benchmark, not a new confirmatory trial. The sole registered result is the archived route-weighted STaR minus FSPC reliability difference on 96 holdout problems. All new comparisons, ablations, and the combined 120-instance results are descriptive/exploratory. The two partitions remain separately identified. Do not tune or select on outcomes.

Use original deposited CON solutions and Phase 3 c64 unchanged: 64 distinct plan trials, 131,072 incremental scenarios, cooperative 5 s wall guard, seed 20261122, 512 maximum optimizer draws per scored plan, three nearby stations, Q=700/h=1, station hours off, synthetic independent lognormal visit waits. No-charge routes remain unchanged and are counted, but are not charging-repair trials; empty exposed cells have NA metrics. Archived holdout control plans/metrics are reused in place without repeat optimization. Run all seven controls on the original 24 development solutions with the Phase 3 independent 10,000-draw final tape (seed 20261123, split key `holdout` also for development; this does not imply unseen data). Do not pool Phase 2.5 4,096-draw results. Keep search and validation work separate. Use six workers with BLAS/OMP threads set to one. Report archive and new runtime cohorts separately, including which methods each cohort measures.

Use the exact frozen function for full STaR, STaR-NPC, and the comparators. The isolated reproduction shares the frozen neighborhood, evaluator, and score. NSP changes the proposal criticality flag only; NAS skips analytical rejection but still ranks by marginal risk; NPP skips both prefix extension and its optimistic pruning. NPC is the frozen bundled omission of amount changes and partial allocation on new topology edits, retaining the source as initial incumbent. Match ordered fingerprints, scores, histories, and counters with all switches on using development-only cases fixed by ordered case and route position. Resume matching checksummed batches only. Persist failures and block release on incomplete pairs. Independently reconstruct and replay every new saved plan, with five scalar reference checks on the same final validation tape. Replay is reproducibility, not a second independent test.

Report means of successes/10,000, point target, one-sided 95% Wilson lower-bound attainment, separate two-sided straddling, and unconditional full depot return including late scenarios, in native units. Also report observed gains/ties/losses; reliability ties use identical success counts, completion ties use absolute tolerance 1e-8, and failure categories distinguish predominant route modes from scenario counts. For paired effects use the same original routes, 9,999 family-stratified parent bootstrap draws, seed 312406; pooled resampling uses family by partition strata (2 development and 8 holdout parents each), keeping A/B and all routes of the parent together. Report separate parent-equal sensitivity and paired common-attainment completion. Secondary intervals are pointwise and unadjusted. Holdout SLS/FSPC control comparisons and mixed-budget secondary profiles remain available in full. Exact topology strata are descriptive and post-selection, not causal.

Main exhibits: exposure by family/variant/partition; mean reliability versus attainment for CON/MWR/QBR/STaR; completion and restoration; ablation paired quality and actual work; family attainment; fixed-plan holdout robustness. Supplementary exhibits: registered FSPC contrast, SLS/FSPC quality/work/runtime and consumed plan trials, topology and NPC, failure uncertainty, fixed R2-A route, all archived stress methods. Assess ablations in component order NPC/NSP/NAS/NPP. Record runtime by archive or new measurement cohort, not a pooled cross-run speed claim. Mandatory writer disclosure: primary STaR–FSPC result and actual trials; STaR–SLS scenario savings and elapsed penalty at c64. Acronyms are defined in `configs/phase5.yaml`.
