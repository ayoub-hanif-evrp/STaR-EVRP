# Phase 3 frozen analysis plan

## Population and endpoint

The 48 held-out Homberger parents, eight per family, contribute both original (A) and relaxed (B) variants. The Phase 1 inventory and Phase 2.5 development allowlist determine membership without performance inspection. Generate deterministic deposited-CON solutions after freeze, independently validate every route and account for all vehicles. Analyze every initially station-exposed route; no-charge routes contribute counts only. The repair-eligible descriptive subset is fixed by B0 final validation point estimate <0.95; do not filter the primary estimand. Missing/invalid baselines or records block confirmatory output rather than shortening the denominator.

The **sole confirmatory endpoint** is the route-weighted mean of STaR minus B4 independent route success probabilities at **64 unique plan trials**, with a two-sided 95% family-stratified percentile cluster-bootstrap interval. A lower endpoint >0 supports an incremental benefit over this fixed-station quantity optimizer. Report the equally weighted mean of nonempty parents as sensitivity. A/B and all routes remain together; bootstrap eight parents with replacement within each of six fixed families, 9,999 draws with seed 312406. Treat parents as exchangeable within family for uncertainty about comparable parents, not scenarios as benchmark replications; the intervals condition on validation estimates. Conditional comparisons omit empty groups/zero denominators and report denominators, not imputations.

## Methods, limits, and model

Use the exact competitive search and physics from the Phase 2.5 release, unchanged. B0 is CON, B1 is mean-wait surrogate search, B2 is uniform independent lognormal quantile risk allocation, B3 uses 512 paired scenarios per scored plan and iterative first improvement, B4 uses the same stochastic search restricted to charge amounts, and STaR adds criticality, a fixed-plan upper bound and optimistic prefix pruning. The no-partial ablation allows topology but uses full charging for new stops. No fleet reassignment, customer reordering or wait-dependent recourse. Q=700, h=1, Euclidean travel and linear station-specific charge rates. Station operating hours are disabled for source compatibility.

All methods use the same limits within profile. Primary: 64 plans, 131,072 scenarios and a 5-second cooperative guard. Secondary: 24 plans with the same other limits; 8,192 scenarios with 128-plan guard; repeat the 64-plan comparison with seed 20261127. B3/B4/STaR run all four profiles. B0–B2 and no-partial run the primary profile. The 40 ms Phase 2.5 diagnostic is not repeated: it is a short machine-specific cooperative limit, not a process deadline. Actual wall duration (including overhead) and process CPU time are recorded on six workers; runtime is descriptive and may reflect scheduler contention. Candidate counts include deterministic rejections, whereas additional scenarios count only new draws. Optimization ends on existing search limits or neighborhood exhaustion.

Final validation is fixed at 10,000 draws for every selected plan, using master seed 20261123 and split `holdout`, independent of optimizer seed 20261122 (or 20261127) and split `opt`. Key by parent, variant, original route ID and ordinal charging slot. Shape changes preserve existing tape prefixes; insertions/deletions shift later slot assignments. The station-specific waits are exp(mu + sigma Z). Validation outcomes include all customer and depot deadlines; completion means unconditional **full depot-return time**, including failed scenarios. Require the pointwise one-sided 95% Wilson lower bound ≥0.95 for attainment. Show point attainment and two-sided Wilson target-straddling separately. The analytical bound only rejects a fixed plan; it never certifies success.

## Secondary comparisons and reporting

Report STaR vs B3 as the key competitive comparison: reliability, attainment, incremental MC draws, wall time and completion. Scenario savings are sample efficiency, not speed. Report unconditional paired completion plus the common LB-attained subset; report mean route-level relative completion using the comparator's positive completion as denominator. All non-primary intervals are descriptive, unadjusted; no simultaneous claims or post-hoc alternative primary endpoint. A general superiority claim is not supported when B3 achieves comparable quality faster.

Break down family/variant, hard R2/RC2 cases, negative failures and uncertainty around 0.95. Mechanism strata are defined by ordered (customer gap, station ID) sequences versus B4; weighted stratum contributions sum to the overall effect, but are descriptive, not a causal decomposition. Show the lexicographically first eligible R2-A route (parent, route ID), regardless of outcome. For each nonattainment label point-positive/lower-negative as uncertain, otherwise report the predominant timing failure (customer only, depot only or both).

Apply fixed-plan synthetic robustness (no optimization, all primary B0/B3/B4/STaR selected plans): multiply wait scale by 1.25, separately multiply lognormal log-scale sigma by 1.25, and separately use an equicorrelated Gaussian copula with rho=0.35, preserving individual margins. Seed 20261124 for ordinal stress shocks and the next seed for the shared normal factor. These are model stresses, not real queue calibration.

Interpretation: lower bound ≤0 for the primary contrast is negative/inconclusive. A positive interval supports a narrow claim unless the B3 comparison additionally favors STaR on quality without worse time or completion; a wall-time loss precludes a strong general claim. No changes after opening performance. An execution/correctness deviation must be disclosed and never treated as a new untouched trial.
