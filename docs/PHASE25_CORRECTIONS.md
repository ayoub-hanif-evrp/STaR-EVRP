## Screen argument

From a feasible zero-wait trace, propagate latest permissible departures backward. At a customer, cap by latest service start and subtract service and travel; at a station subtract charge duration and travel, and cap by closing if enabled. Ready-time floors can only delay progress, so omitting downstream floors cannot make this necessary constraint too tight. Subtract the station's zero-wait departure from the propagated deadline, using an outward numerical cushion at benchmark scales. If an isolated wait exceeds this cap, no larger joint wait vector can succeed under the fixed plan. Therefore the minimum marginal CDF is an upper bound on route success, even without independence for that inequality; under independence the product is also an upper bound. The production screen uses the minimum and a strict comparison with numerical slack, and never discards a below-target incumbent's potentially useful candidate on that basis. “Target reached in search” still refers to the tape estimate, not a proof of the incumbent's population reliability. Safe screening is not an acceptance certificate or a topology-level impossibility result.

Prefix pruning is separate: optimistic reliability assumes every remaining scenario succeeds, and optimistic mean completion charges remaining draws zero-wait completion. If even that lexicographic score cannot beat the incumbent on the fixed tape, stop sampling that challenger. Vector timing was checked against full-route scalar reference scenarios during replay.
